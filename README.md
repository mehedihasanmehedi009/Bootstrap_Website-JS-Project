# Blooming Oasis — Bootstrap website

A responsive four-page front-end concept made with Bootstrap 5.3, Bootstrap Icons, custom CSS and vanilla JavaScript.

## Pages
- `index.html` — homepage, plant-matchmaker quiz, featured plants, collections and care CTA
- `product.html` — product details, care/toxicity/repotting information, pot/stand add-ons, quantity selector and demo cart
- `about.html` — brand story, sourcing values and editable sample team profiles
- `contact.html` — contact form, FAQ and demo plant-care chat assistant

## Run locally
Open `index.html` in a browser. Internet is needed for Bootstrap CDN, Google Fonts and Unsplash photography.

## Before production launch
- Replace sample brand story, team identities/photos, prices and contact address with verified details.
- The cart and checkout are front-end demonstrations only. Connect product inventory, order processing and a payment provider.
- Connect contact/newsletter forms to a secure backend or a trusted form/email service.
- Connect the chat assistant to a real support workflow if live staffed advice is advertised.
- Audit image licenses/usage, plant availability, delivery/returns policies, and accessibility.
